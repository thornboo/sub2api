# 公开模型列表与价格页

> 状态：已落地（2026-07-30）。
> 适用范围：从 Home 首页进入、无需登录的独立模型列表页面。页面展示普通新用户可见的公开分组、模型、公开倍率、价格与 API 端点。

## 结论

复用现有 `/model-plaza` 路由，把它收敛成公开模型列表，而不是在 Home 页面内直接铺开全部模型，也不再新增第三套模型目录。

公开页面与登录后的 `/available-channels` 共用同一套模型、价格和交付端点投影，区别只在可见分组范围：

| 页面 | 登录要求 | 分组范围 |
| --- | --- | --- |
| `/model-plaza` | 无需登录 | 仅普通新用户默认可见的公开标准分组 |
| `/available-channels` | 需要登录 | 公开分组 + 当前用户被授权的专属分组 + 当前用户有效订阅分组 |

公开页面不因请求是否携带登录 token 而改变内容。已登录用户访问 `/model-plaza` 时，仍然只看到公开标准分组；专属分组、订阅分组和用户专属倍率继续只出现在登录后的 `/available-channels`。

## 背景

改造前，Home 页面已有模型宣传区域，但模型名称和价格来自前端硬编码，“查看更多模型”又跳转到需要登录的 `/available-channels`。访客无法在注册前确认站点实际提供的模型、价格和 API 端点。

仓库已经存在：

- 公开路由 `/model-plaza`。
- `GET /api/v1/model-plaza`。
- `ModelPlazaView` 及其分组、价格组件。
- `model_plaza_enabled` 与 `model_plaza_require_auth` 设置。
- 登录后的 `AvailableModelMarketplace`、价格格式化和模型交付端点投影。

本功能不从零创建模型页，而是修正并复用这些现有能力。

## 目标

- 访客无需注册登录即可查看站点公开提供的模型。
- 页面按公开分组组织模型，与普通用户登录后的公开部分保持一致。
- 展示公开分组默认倍率和按该倍率计算后的站点价格。
- 展示模型在该公开分组下可供客户调用的 API 端点。
- Home 首页提供清晰入口，但不在 Home 页面内嵌完整模型列表。
- 公开页与登录页复用同一套模型交付判断、价格格式化和卡片组件，避免口径漂移。

## 非目标

- 不在 Home 页面直接加载和展示完整模型目录。
- 不展示专属分组、用户专属倍率或用户订阅分组。
- 不展示上游账号、上游 Base URL、API Key、账号优先级或故障切换拓扑。
- 不新增模型健康状态、实时可用率或上游错误展示。
- 不新增报价导出、分享链接、报价模板或历史报价快照。
- 不改变真实计费、模型映射、账号调度或协议转换逻辑。
- 第一版不要求展示 LiteLLM 官方参考价；站点公开价格是主信息。
- 不新增数据库表。

## “公开分组”的确定口径

第一版中的公开分组指普通新注册用户不需要额外授权即可看到的标准分组：

- 分组状态为 `active`。
- `is_exclusive = false`。
- `subscription_type = standard`。

以下内容不进入公开模型列表：

- 专属分组，即 `is_exclusive = true`。
- 需要有效订阅才能使用的订阅分组。
- 已禁用或已删除分组。
- 仅管理员可见的完整渠道目录。

这一定义复用 `/available-channels` 现有的“仅公开”范围，不建立新的权限标签。

## 页面入口与导航

### 路由

继续使用：

```text
/model-plaza
```

页面标题使用“模型列表”或“模型广场”，英文使用“Model Catalog”或现有“Model Plaza”。路由不需要迁移为 `/models`。

### Home 首页

Home 页面只增加入口，不内嵌完整目录：

- 公共顶部导航增加“模型列表”。
- 现有 Models 区域的“查看更多模型”从 `/available-channels` 改为 `/model-plaza`。
- 页面启用时，访客点击后直接进入公开模型列表，不经过登录页。
- 页面关闭时，不显示入口；直接访问仍由后端开关 fail-closed。

### 登录后入口

已登录用户仍可从控制台进入 `/available-channels` 查看自己的完整可用范围。若控制台保留 `/model-plaza` 入口，它进入的仍是相同公开目录，不追加专属内容。

## 页面信息结构

页面沿用“分组 -> 模型卡片”的结构。

### 页头

- 页面名称。
- 管理员配置的公开说明。

### 筛选

第一版使用单行紧凑筛选栏：

- 模型名称搜索。
- 平台下拉筛选。
- 公开分组下拉筛选。

平台与分组复用项目通用下拉控件并互相约束，不匹配当前选择的选项保持禁用；倍率已经显示在分组标识和价格中，不再作为筛选条件。也不增加专属、订阅或用户范围筛选，因为这些数据不会进入公开响应。

### 分组区块

每个公开分组展示：

- 分组名称。
- 平台。
- 分组描述。
- 默认倍率。
- 峰值倍率和时间窗口（如果该公开分组已启用）。
- 该分组下当前可展示的模型数量。

### 模型卡片

每个模型展示：

- 公开模型名称。
- 模型图标和平台。
- 站点价格或多个价格方案提示。
- 当前公开分组下可调用的 API 端点。
- 现有用户模型广场已经展示的公共渠道名称；不展示对应上游账号。
- 复制模型名称和 API 端点的操作。

同一模型在不同公开分组中分别展示；同一公开分组内的同名模型跨渠道聚合为一张卡片，与 `/available-channels` 的当前模型广场一致。

## 价格口径

公开页不读取用户专属倍率。生效倍率固定为公开分组的默认倍率：

```text
公开实付价 = 渠道模型定价 × 公开分组默认倍率
```

价格展示复用现有计费类型：

- 按 Token。
- 按次。
- 按图片。
- 阶梯定价。
- 缓存写入和缓存读取价格。

同一“公开分组 + 模型”只有一个价格方案时，直接显示实付价格。

存在多个渠道价格方案时：

- 不任意选择最低价。
- 显示“多个价格方案”及数量。
- 允许在卡片详情或现有价格展示中查看每个方案。

页面不返回和不计算 `user_rate_multiplier`，也不使用用户登录身份改变价格。

## 模型与 API 端点口径

公开页必须复用 `/available-channels` 的交付投影，不能继续只依据“渠道配置了模型映射或价格”生成目录。

模型卡片的分组归属使用：

- `route_group_ids`：模型在该公开分组下是否存在稳定交付路线。

API 端点使用：

- `supported_endpoints[].group_ids`：该端点是否属于当前公开分组。
- `supported_endpoints[].path`：客户实际调用的 sub2api 路径。

端点可能包括：

- `/v1/messages`
- `/v1/chat/completions`
- `/v1/responses`

页面不根据分组平台、渠道平台、模型名称或价格配置自行猜测端点。没有交付投影证据的端点不展示。

目录元数据可以忽略短时并发占满、冷却和瞬时健康波动，避免公开页面频繁闪烁；但不能使用已停用、不可调度、平台不匹配或模型不匹配的账号证明模型可交付。

## 登录前后的一致性

公开接口的结果只由公开分组和当前站点配置决定，不由当前用户决定：

```text
匿名 GET /api/v1/model-plaza
        ==
已登录 GET /api/v1/model-plaza
```

这里的“相等”指：

- 分组集合相同。
- 模型集合相同。
- 默认倍率相同。
- 价格相同。
- API 端点相同。

登录用户自己的专属分组、订阅分组和专属倍率仍通过 `/api/v1/channels/available` 获取。

## 接口边界

继续使用：

```text
GET /api/v1/model-plaza
```

目标响应至少支持：

- 页面公开说明。
- 公开分组元数据。
- 分组下的模型卡片数据。
- 模型价格。
- 分组级 `route_group_ids` 和 `supported_endpoints` 投影结果。

实现时应从现有可用渠道服务中提取或复用“给定分组集合生成客户安全目录”的公共逻辑：

```text
公开模型列表
  -> 查询公开标准分组
  -> 调用共享可用渠道/交付投影
  -> 返回公开 DTO

登录可用渠道
  -> 查询当前用户可访问分组
  -> 调用同一共享可用渠道/交付投影
  -> 返回用户 DTO
```

不能让 `ModelPlazaHandler` 和 `AvailableChannelHandler` 分别维护两套模型可交付规则。

公开 DTO 可以包含现有客户侧模型目录字段，但不能包含：

- 上游账号 ID 或名称。
- 上游 URL。
- 上游模型能力原始记录。
- 账号调度顺序。
- 管理员成本。
- 用户 ID、用户专属分组或用户专属倍率。

## 现有开关

保留现有设置，避免无关的配置迁移：

- `model_plaza_enabled`：控制公开模型页和 Home 入口是否启用。
- `model_plaza_require_auth`：本功能的目标运行值为 `false`。
- `model_plaza_description`：公开页面说明。

第一版不删除 `model_plaza_require_auth` 的存量兼容能力，但本功能只有在下面组合下满足“注册前可查看”的产品目标：

```text
model_plaza_enabled = true
model_plaza_require_auth = false
```

## 前端复用边界

优先复用：

- `ModelPlazaView`：独立公开页面和导航外壳。
- `AvailableModelMarketplace`：分组和模型卡片。
- `buildAvailableModelMarketplaceCards`：同组同模型跨渠道聚合。
- `availableChannelsCatalog`：价格和计费格式化。
- `GroupBadge`、`ModelIcon`、`PlatformIcon`、`Icon`。

`ModelPlazaContent` 已改为复用登录后可用渠道页的卡片与聚合工具；旧 `PlazaGroupSection`、`PlazaModelPricingTable` 及其仅服务旧响应的官方参考价类型已经删除，仓库不再维护第二套模型、价格和端点规则。

不新增 UI 依赖，继续使用 Vue 3、TypeScript、现有 Tailwind 风格和 stone / neutral / emerald 视觉方向。

## 页面状态

### 加载

- 显示与现有模型卡片尺寸接近的骨架屏。
- 不因公共设置和模型数据分别加载而短暂跳转到登录页。

### 空状态

- 开关已启用但没有符合条件的公开模型时，显示“当前暂无公开模型”。
- 不把专属或订阅分组数量暴露在空状态文案中。

### 错误

- 接口失败时显示可重试错误。
- 保留公共导航，不跳转登录页。
- 独立页面右上角按登录态显示返回入口：登录用户“返回控制台”，未登录访客“回到首页”。

### 关闭

- `model_plaza_enabled = false` 时，后端继续返回 404。
- Home 不显示模型列表入口。

## 响应式与可访问性

- 桌面端保持多列卡片。
- 移动端单列展示，长模型名不能撑开页面。
- 搜索、筛选、复制按钮和链接可通过键盘访问。
- API 端点和价格不能仅在 hover 中展示。
- 价格、端点和不可用状态不能只依赖颜色表达。
- 复用现有中英文国际化体系，不在模板中新增仅中文硬编码。

## 落地组成

本功能按以下顺序完成：

1. 提取或复用给定分组集合的客户安全目录投影。
2. 将 `/api/v1/model-plaza` 固定为公开标准分组，不再根据登录用户追加专属内容。
3. 让公开模型响应使用与 `/available-channels` 相同的模型路由、价格和端点口径。
4. 改造公开页面复用 `AvailableModelMarketplace` 和现有价格工具。
5. Home 公共导航和 Models 按钮链接到 `/model-plaza`。
6. 补充中英文文案。
7. 功能状态、接口索引、变更记录、补丁记录和验证矩阵同步更新。

## 验收标准

- 未登录访客可以从 Home 进入 `/model-plaza`，不会被重定向到登录页。
- 页面是独立页面，Home 不直接渲染完整模型目录。
- 页面只展示 active、standard、非专属的公开分组。
- 已登录用户访问公开页面不会额外看到专属分组、订阅分组或用户专属倍率。
- 普通用户在 `/available-channels` 看到的公开分组、模型、公开倍率、价格和端点，与 `/model-plaza` 一致。
- 同一公开分组内同名模型跨渠道只生成一张卡片；跨分组分别展示。
- 价格按公开分组默认倍率计算；多个价格方案不静默选择最低价。
- 模型只在对应 `route_group_ids` 包含该公开分组时进入该分组卡片。
- API 端点只在 `supported_endpoints` 对该公开分组有证据时展示。
- 被禁用、不可调度、平台不匹配或模型不匹配的账号不能证明模型可交付。
- 响应中不包含上游账号、上游 URL、管理员成本、用户专属分组或用户专属倍率。
- `model_plaza_enabled = false` 时 Home 入口隐藏且接口 fail-closed。
- 暗色模式、移动端、中英文、加载、空和错误状态可用。
- 无需数据库迁移，不改变真实计费和运行时转发。

## 推荐验证

### 后端

- 匿名访问启用后的 `/api/v1/model-plaza` 返回 200。
- 携带普通用户 token 与匿名请求返回相同公开目录。
- 被授权专属分组的用户访问公开接口时，响应仍不包含该专属分组。
- 有效订阅用户访问公开接口时，响应仍不包含订阅分组。
- 只有价格但没有稳定交付路线的模型不进入可用卡片。
- 多账号支持不同协议时，端点集合只包含对应公开分组下已确认的客户可调用端点。
- 禁用开关返回 404。
- DTO 白名单测试确认没有账号、URL、成本和用户专属字段。

### 前端

- Home 导航和 Models 按钮都跳转 `/model-plaza`。
- 匿名路由不会触发登录重定向。
- 搜索、平台和分组下拉筛选正常；桌面宽屏保持同一行，窄屏按空间自然换行。
- 分组、模型、倍率、实付价格、多个价格方案和 API 端点正确渲染。
- 不渲染专属、订阅和用户专属倍率。
- 移动端长模型名、价格和端点不会横向撑破页面。
